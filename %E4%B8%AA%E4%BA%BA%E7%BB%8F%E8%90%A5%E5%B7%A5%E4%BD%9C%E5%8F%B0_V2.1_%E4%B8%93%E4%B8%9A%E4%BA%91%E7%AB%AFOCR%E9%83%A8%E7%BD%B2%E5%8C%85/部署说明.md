# 个人经营工作台 V2.1：云端高精度 OCR 上线说明

## 当前交付状态

已完成**专业 OCR 接口接入代码**和工作台页面对接；**尚未实际部署上线**，因为此处没有你授权的 Vercel / Supabase 项目及腾讯云 OCR 凭证。目前的验证包含：静态代码检查、模拟腾讯云 OCR 响应、模拟账号校验和页面自动填字段。没有真实腾讯云 API 凭证，因此**不能宣称真实面单的云端识别准确率已通过验证**。

本版本与以前不同：**不再是单 HTML 离线识别**，因为你已经同意云端识别。上线后必须连接网络才能识别面单和跨设备同步；断网时仍可以手动录单并导出本地备份（已登录、已缓存页面的前提下），但不能发送 OCR 请求。

## 文件说明

- `index.html`：工作台完整界面，含批量图片上传、逐张识别/核对、计费、客户管理、历史订单、付款记录和项目管理。
- `api/ocr.js`：同源 Vercel Node.js Function；验证已登录的 Supabase 用户，再调用腾讯云 **GeneralAccurateOCR**。
- `lib/parse-label.cjs`：将识别出的文本转换为物流单号、收货人、省份、计费重量。
- `database.sql`：与 V2.0 相同的 Supabase 数据表和 RLS 权限控制。
- `vercel.json`：安全响应头配置。
- `tests/check.cjs`：模拟服务端测试，`node tests/check.cjs`。

## 第一步：准备 Supabase（已有 V2.0 项目则沿用）

1. 在 Supabase 创建项目，进入 SQL Editor 运行 `database.sql`，开通邮箱登录（建议验证邮箱）。若已部署 V2.0，**不要删除数据库或重新初始化你的账目**，直接沿用原数据库。
2. 到项目 API 设置找到 **Project URL** 和 **publishable key / anon key**。
3. 在 `index.html` 中搜索：

   `const CLOUD_BOOTSTRAP={url:'',anonKey:''};`

   只填入真实的 Project URL 和 **公开** `publishable / anon` key，绝不填写 `service_role`、`sb_secret_` 或数据库密码。

## 第二步：开通腾讯云 OCR

1. 在腾讯云控制台注册/登录，启用文字识别 OCR 服务，确认「通用文字识别（高精度版）」可调用，并了解接口按量计费情况及使用额度。
2. 创建带有 OCR 调用权限的 API 密钥，取得 `SecretId` 和 `SecretKey`。
3. **密钥只写入 Vercel 环境变量，不应发到聊天里，也不应写入 HTML、Git 仓库或备份文件。** 如可能，限制密钥的 IAM 权限与使用范围；设置账单预算/额度提醒。

参考：https://cloud.tencent.com/document/product/866/34937

## 第三步：用 Vercel 发布整个项目文件夹

**不能只发布 HTML 文件。** 需要部署 `index.html`、`api/ocr.js`、`lib/parse-label.cjs`、`vercel.json` 及相关文件，使 `/api/ocr` 成为网站的服务端接口。

在 Vercel 创建项目，并将此文件夹作为项目根目录。构建方式可用 `Other / 无框架`，不需额外 npm 安装。配置以下环境变量（Production / Preview 按需要分别设置）：

| 环境变量名 | 说明 |
|---|---|
| `SUPABASE_URL` | 你的 Supabase 项目 HTTPS URL，必须与网页内 CLOUD_BOOTSTRAP 指向同一个项目 |
| `SUPABASE_PUBLISHABLE_KEY` | 对应项目公开的 publishable / anon key；非管理员秘钥 |
| `TENCENT_SECRET_ID` | 腾讯云 SecretId，仅服务器端保存 |
| `TENCENT_SECRET_KEY` | 腾讯云 SecretKey，仅服务器端保存 |
| `TENCENT_REGION` | 可选；默认 `ap-guangzhou` |

环境变量配置完成后**重新部署**，让 Vercel 函数加载它们。在 Supabase Authentication → URL Configuration，将 Vercel 上线域名设置到允许的站点 / 重定向 URL 中。

## 第四步：验收

1. 在手机和电脑分别打开同一 Vercel HTTPS 网址，用同一个 Supabase 账号登录。
2. 如果已有旧版数据，先从旧版「数据与设置」导出 JSON 备份，再在新工作台恢复；切勿无备份地覆盖。
3. 在「面单报价」先选择客户，上传一张清晰的顺丰面单，点击 **云端识别本张**。
4. 观察返回的 OCR 原文及自动提取的**物流单号、收货人、收货省份、计费重量**，逐项对照照片核实。框选局部区域可以重新识别。
5. 核对后使用客户报价表和统一成本表计算基础运费/包装费/利润，再保存订单。最后用第二台设备检查同步情况。
6. 用真实实拍面单（逆光、反光、倾斜等）做实际验收，记录识别错误率。云端 OCR 也可能识别错；**不要直接自动生成/保存未经人工核对的财务订单**。
7. 用「备份数据」导出离线 JSON，并存到独立安全位置。

## 图片隐私与费用

- 上传后浏览器**仅临时发送压缩后的图片**到同源 `/api/ocr`；服务端使用 HTTPS 将图片交给腾讯云 OCR，取回识别文字。
- 代码不调用 Supabase 存储 API 保存图片，也不写入服务器文件或日志；只把识别字段填入表单。批量上传的预览图片在当前浏览器页面会话中暂存，关闭/切换后可释放。
- **无法代替第三方作出绝不留存的承诺。** 腾讯云或运行平台可能根据自身的服务条款/日志与数据处理政策处理请求；如果使用真实客户面单，需确认数据处理和隐私合规要求。
- OCR 调用可能按量收费，每点击一次云端识别/局部重新识别都可能产生一次调用；批量单张处理没有自动隐藏调用。
- 服务端必须验证 Supabase 登录令牌，且 OCR 密钥从未发送到前端。浏览器只保存公开的 Supabase key。
- 图片最大 2.8MB Base64 左右；前端会在上传前自动压缩或缩放，以避开 Vercel 4.5MB 请求上限，过大将报错。

## 常见错误

- **“云端 OCR 接口尚未部署”**：只上传了 HTML，没上传完整项目文件夹。
- **“云端 OCR 尚未配置”**：缺少 Vercel 环境变量，或尚未重新部署。
- **“登录已过期”**：重新登录工作台；确认 Vercel 的 SUPABASE_URL / KEY 与网页配置一致。
- **“识别服务返回错误”**：检查腾讯云 OCR 是否开通，密钥权限、SecretId/SecretKey 和调用额度是否正确。
- **“请求超时”**：检查设备网络、云函数和腾讯云接口状态。
- **部分字段为空或识别不正确**：展开识别文字、框选局部重新识别或手动录入。照片质量、地址版式和字体都会影响识别效果。
